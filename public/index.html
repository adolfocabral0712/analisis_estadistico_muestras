AVANCE DEL MUESTREO
CONFIANZA 95 %: el análisis estadístico se realiza con un nivel de confianza del 95 %.
ERROR MÁXIMO ±5 %: el error relativo objetivo establecido para considerar suficiente el muestreo es de ±5 %.
t DE STUDENT: se utiliza la distribución t de Student; los grados de libertad se calculan como n - 1.
POBLACIÓN FINITA: el error actual, el intervalo de confianza y el tamaño de muestra requerido incorporan la corrección por población finita. La población N corresponde a los remitos de cada Año operativo + Mes operativo + Monte + Producto.
PERÍODO 26 → 25: cada mes operativo comprende desde el día 26 del mes anterior hasta el día 25 del mes indicado.
DEPÓSITO FRIMOSA: la población analizada corresponde únicamente a remitos del depósito FRIMOSA.
EXCLUYE TROZA: no se consideran productos cuyo nombre contenga TROZA. El dashboard muestra información desde 2025 en adelante y excluye además montes cuyo nombre contenga BALANZA.
N REQ. GRANDE: cantidad de muestras necesarias suponiendo una población muy grande o infinita, usando t de Student y el error objetivo de ±5 %.
N REQ. FINITA: cantidad de muestras necesarias considerando la población real de viajes/remitos del grupo y aplicando la corrección por población finita.
FALTAN: cantidad de muestras adicionales necesarias para alcanzar el tamaño de muestra requerido con población finita. Si el valor es 0, el grupo ya alcanzó o superó el mínimo requerido.
gl: grados de libertad utilizados para obtener el valor crítico de t de Student. Se calculan como n - 1.
t CRÍTICO: valor crítico de la distribución t de Student correspondiente a los grados de libertad del grupo y a un nivel de confianza del 95 %.
ERROR PROMEDIO: promedio aritmético del error actual porcentual de los grupos que quedan visibles según los filtros seleccionados. Los grupos SIN ESTIMAR no participan del promedio.
